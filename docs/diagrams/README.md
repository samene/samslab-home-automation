# Diagrams

## Purpose

Provide a home for source-controlled architecture diagrams that complement the Mermaid diagrams embedded in documentation.

## Scope

Diagram source and exported review artifacts only; no application implementation.

## Architecture

Use Mermaid in Markdown for diagrams that benefit from inline review. Store editable source for complex diagrams here and keep it aligned with the owning architecture document.

## Design Decisions

Diagrams describe responsibilities and trust boundaries, not undocumented implementation details.

## Future Considerations

Add C4 context/container diagrams and operational runbook visuals as the system is built.
